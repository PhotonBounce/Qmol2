Windows

Self-hosted desktop app. Runs the full API locally. No cloud required. Python 3.12 + RDKit included.

Download ZIP (8 MB) GitHub

Requirements

  • Windows 10/11 (64-bit)
  • 8 GB RAM recommended
  • Python 3.12 (auto-installed if missing)
  • Internet connection (for PubChem queries)
> # Quick start > unzip qmol-windows.zip > cd qmol > start.bat
