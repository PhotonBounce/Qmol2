## Kaggle Dataset Description

```
# Q-Mol Drug-Like Molecules Dataset

## Description
Curated molecular dataset with full ADMET descriptors computed using RDKit 
and validated against PubChem.

## Columns
- smiles: RDKit-validated SMILES
- mw: Molecular weight (g/mol)
- logp: XLogP (lipophilicity)
- tpsa: Topological polar surface area (Å²)
- qed: Quantitative Estimate of Drug-likeness (0-1)
- hbd: Hydrogen bond donors
- hba: Hydrogen bond acceptors
- lipinski_pass: Passes Lipinski Rule of 5 (1/0)
- pains_hit: Matches PAINS filter (1/0)

## Source
PubChem CIDs harvested via Q-Mol platform

## License
CC BY 4.0 for academic use. Commercial licensing available.

## Contact
qmol@photon-bounce.com
```
